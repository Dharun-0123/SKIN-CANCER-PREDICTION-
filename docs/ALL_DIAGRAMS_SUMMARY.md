## 🔧 Customization Tips

### Change Colors
```mermaid
style NodeName fill:#HEXCOLOR,stroke:#333,stroke-width:2px
```

### Adjust Layout
- Use `TB` (top-bottom), `LR` (left-right), `RL`, `BT`
- Example: `graph LR` instead of `graph TB`

### Add More Detail
- Add more nodes
- Add more connections
- Add subgraphs for grouping

1. **Use SVG for papers** - Vector graphics scale perfectly
2. **Test grayscale** - Print preview before submission
3. **Keep it simple** - Don't overcomplicate diagrams
4. **Label clearly** - All components should be identifiable
5. **Reference in text** - Always mention "Fig. X" in paper
6. **Consistent style** - Use same color scheme throughout
7. **High quality** - Minimum 300 DPI for raster
8. **Follow guidelines** - Check journal-specific requirements
